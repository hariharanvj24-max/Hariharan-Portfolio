## 🚀 Quick Start / How to Run

### Method 1: Direct Browser Launch
Simply double-click or open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Firefox, Brave, Safari). No build tools, package managers, or server installations are required!

### Method 2: Local HTTP Server (Optional)
If you prefer running via a local server:
```powershell
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```
Then navigate to `http://localhost:8000`.
